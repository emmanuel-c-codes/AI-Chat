GitHub is a cloud-based platform where developers store, share, and collaborate on their software projects.

Think of it as a social network and Google Docs, but specifically for programmers.

To understand GitHub, it helps to break it down into two parts: Git and Hub.

1. What is Git? (The System)
Git is a "version control system." It acts like a time machine for your code.

Every time you make a change to your project, you can save a snapshot of it (called a "commit").
If you make a mistake or your code breaks, you can easily roll back to a previous version.
It allows multiple people to work on the exact same project at the same time without overwriting each other's work.
2. What is the "Hub"? (The Platform)
The Hub is the website (GitHub.com) that connects developers. It takes the Git system and puts it online. On GitHub, you can:

Host your code online so it’s backed up and accessible from anywhere.
Collaborate with others on team projects.
Share your work with the world. Many developers use GitHub as a portfolio to show potential employers what they can build.
Contribute to "Open Source" projects, which are free software projects that anyone in the world can help build (like Linux, VS Code, or Python libraries).
A simple analogy:
Writing a book alone: You write on your computer. If your computer breaks, you lose it. If you want to change a chapter, you might save it as book_draft_v2.docx.
Writing a book with GitHub: The book is saved safely online. You and five friends can write different chapters at the exact same time. If someone writes a bad chapter, you can click a button to erase their changes and go back to yesterday's version.
